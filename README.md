# Interia Logistique — Mockup interactif

Projet React/Vite prêt à lancer et à déployer.

## Lancer en local

```bash
npm install
npm run dev
```

## Partager via Vercel

1. Créer un repository GitHub avec ces fichiers.
2. Aller sur Vercel.
3. Importer le repository.
4. Framework détecté : Vite.
5. Build command : `npm run build`.
6. Output directory : `dist`.
7. Déployer.
8. Partager le lien Vercel.

Le fichier `index.html` contient `noindex, nofollow` pour éviter une indexation naturelle par les moteurs de recherche.
